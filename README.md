# Quesz Links

Astro static site for Quesz's profile, interests, projects, live stats, music player, and Bad Apple ASCII video.

## Development

```sh
npm install
npm run dev
```

Build the production site with `npm run build`. The generated static files are written to `dist/`.

## Cloudflare Pages

- Build command: `npm run build`
- Build output directory: `dist`
- Production URL: `https://quesz.pages.dev`
